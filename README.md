AlgoVision – Interactive DSA Visualizer

AlgoVision is an interactive web project designed to help students understand Data Structures and Algorithms (DSA) through visualizations, step-by-step explanations, and algorithm complexity analysis.

Features

- Sorting algorithms: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort
- Searching algorithms: Linear Search, Binary Search, Jump Search, Interpolation Search, Exponential Search
- Step-by-step algorithm visualization
- Playback controls to navigate through steps
- Live statistics for comparisons, swaps, and array writes
- Python code examples
- Responsive user interface

Technologies Used

- HTML
- CSS
- JavaScript
- Python code examples

How to Run

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. Select an algorithm and experiment with the visualization.

Project Status

Frontend prototype under development. Python code examples are displayed in the interface; backend integration can be added separately.

Author

Developed as a student project to make learning DSA more visual and interactive.
